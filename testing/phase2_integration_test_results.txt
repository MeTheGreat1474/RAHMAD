--------------------------------------------------------------------------------
Purpose: Verify end-to-end orchestration across all 6 core modules:
1. Input Processing (backend/input_processing.py)
2. Early Predictor CLIP+LoRA (model/early_predictor.py)
3. Knowledge Retrieval Web/Semantic Search (model/knowledge_retrieval.py)
4. Reverse Image Search (model/reverse_image_search.py)
5. Multi-Agent Debate 6-Agent Discourse (model/mad_orchestrator.py)
6. Judge Reasoning Layer (model/judge.py)
along with intermediate status streaming, graceful failure resilience, input
guards, and structured pipeline logging.

Test Cases Conducted:
1. test_full_pipeline_flow_all_modules_success
   - Input: Valid multi-paragraph article text (>10 chars) and a valid base64 PNG image data-URI.
   - Verification: Executes all 7 pipeline progression steps:
       [PRE-PROCESSING INPUT... -> RUNNING EARLY PREDICTOR... -> FETCHING EVIDENCE... ->
        SEARCHING FOR SIMILAR IMAGES... -> DEBATING... -> SYNTHESIZING RESULTS... ->
        OUTPUTTING PREDICTION...]
     Verifies all status steps transition from IN PROGRESS to OK. Asserts final payload contains
     all mandatory verdict schema keys ('verdict', 'color_class', 'confidence', 'justification',
     'key_facts', 'links', 'ep_signal'). Confirms links are extracted from external news reports
     and Early Predictor tensor outputs are properly captured.
   - Result: PASS

2. test_pipeline_text_only_no_image

   - Verification: Vision-dependent modules (Early Predictor and Reverse Image Search) are
     gracefully bypassed and stream status flags mark them as 'SKIPPED'. Verifies the Judge
     receives a neutral Early Predictor fallback signal (label='UNKNOWN', probability=0.5)
     allowing text-only analysis to successfully conclude with a valid verdict.
   - Result: PASS

3. test_pipeline_short_text_rejection

   - Verification: Input guard triggers immediately, halts downstream heavy module execution,
     and instantly emits an 'INCONCLUSIVE' result (confidence='0.0%') instructing the user
     to submit a complete article.
   - Result: PASS

4. test_pipeline_empty_or_whitespace_text_rejection
   - Input: Empty strings ("") and whitespace-only text ("   ", "\n\t  \n").
   - Verification: Immediately yields 'INCONCLUSIVE' without invoking any downstream models.
   - Result: PASS

5. test_pipeline_invalid_image_data_graceful_fallback
   - Input: Valid news text accompanied by an invalid/unparseable image string ("not_a_valid_data_url").
   - Verification: Pipeline image decoder detects unsupported formatting, logs a warning, and
     seamlessly falls back to text-only mode without crashing the NDJSON stream or server.
   - Result: PASS

6. test_pipeline_judge_mode_single
